# Il mio Piano — sito

Sito vetrina di **Il mio Piano**, l'app che aiuta i pazienti a seguire il piano nutrizionale elaborato dal proprio professionista: menu del giorno, promemoria dei pasti, lista della spesa e sostituzioni indicate dal nutrizionista.

🌐 **Sito:** https://ilmiopiano.it
✉️ **Contatti:** info@ilmiopiano.it

## Contenuto del repository

| File | Pagina |
|---|---|
| `index.html` | Home: presentazione, funzioni, prezzi e modulo di acquisto |
| `privacy.html` | Informativa privacy e cookie |
| `termini.html` | Termini di servizio |
| `accordo-trattamento-dati.html` | Accordo sul trattamento dei dati (art. 28 GDPR) |

## Come aggiornare il sito

1. Apri il file da modificare e tocca la matita (*Edit this file*).
2. Fai le modifiche e premi **Commit changes**.
3. Il sito si aggiorna da solo in circa un minuto.

I link di pagamento e l'indirizzo dell'app si modificano in `index.html`, nella sezione `CONFIG_IMP` verso la fine del file.

## Pubblicazione

Il sito è pubblicato con GitHub Pages sul dominio ilmiopiano.it.
Non eliminare il file `CNAME`: GitHub lo crea quando colleghi il dominio e serve a mantenere il collegamento.
